# 安全重構流程（細則）

1. **建立基準**：記錄改前的測試、型別檢查、建置結果與關鍵輸出（快照）；`tools/depgraph.py <root> --json before.json` 存依賴圖。
2. **保護措施先行**：對要動的模組建「固定輸入→固定輸出」比對（快照測試、輸出逐值比對腳本）。
3. **小步、可回復**：每批一個獨立 commit，可單獨 revert；每批只做一種變更（抽常數、拆檔、解循環）。
4. **行為不變的證明**：純重構改前後輸出逐值／逐字元相同；有意改變的行為另開 commit 並寫進「有意改變的行為」清單。
5. **結構原則**：資料與邏輯分離（大型清單獨立成檔）；長文字具名成常數；隱藏前置條件集中到唯一入口並寫在簽名／文件；同樣樣板 3 處以上才抽共用；表面相似但刻意不同的寫清楚為何不合併。
6. **閘門**：`tools/depgraph.py <root> --max-cycle-files <基準>` 循環不可增加；分層規則用 `--forbid`。
7. **刪除前**確認沒有任何呼叫端（含腳本、排程、測試、文件指名），刪後全套檢查必過。
