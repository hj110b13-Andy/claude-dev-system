## 規則十：節省 token

- **查資料要精準**：限定資料夾／檔案類型、限制回傳筆數；只讀需要的行數範圍；這次對話讀過且沒變的檔案不重讀。
- **行動範圍對齊使用者的要求**：只是確認狀態或單純提問時，不要聯想到品保流程就擴大去做額外的事（例：只問「有沒有推送完全」不用派 agent 做功能測試）；不確定範圍時先做最小可行回應。
- **沒有先後依賴的指令合併成一次執行**，工具呼叫次數越少越省。這些是原則性提醒，能省則省。
