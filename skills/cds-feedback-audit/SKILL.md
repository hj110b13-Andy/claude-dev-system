# 回饋稽核模板（claude-dev-system）

> 模板：各專案要自行指定「回饋從哪裡讀」的腳本與「上次檢查時間」記在哪裡（寫在專案 CLAUDE.md）。

1. **讀全部**：從上次檢查時間（記錄腳本實際執行當下的 UTC，不可往後記）起，一字不漏讀完全部回報與紀錄（含正面評價）；自動旗標只是輔助，抓不到推理錯誤與誤導。
2. **先查證不照單全收**：對照回報當下的資料與狀態（不能拿現在的資料判斷當時），用程式行為、實際重現確認「屬實／不屬實／待查」。
3. **修整類**：屬實的找根因，再問「還有哪些地方踩到同一根因」，用通用規則一次修好並加涵蓋各類的測試或評測題；不可只加特例。
4. **逐筆回覆**：表格列「時間＋回報內容（精簡引述）＋查證結果＋處理方式（誰做、哪一批、何時驗證）」；沒有新回報就一句話。
5. **記錄**：檢查時間與結論寫進專案交接紀錄；要修的排進待辦清單。
